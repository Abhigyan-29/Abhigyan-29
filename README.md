### 01. Distributed File Storage System

<sub>JAVA / SPRING BOOT / POSTGRESQL / DOCKER / KUBERNETES</sub>

A distributed storage backend exploring how files can be processed, transferred, replicated, and monitored across a storage system.

**What I built and explored**

- File chunking to divide large files into manageable units.
- Parallel upload and download workflows using Java `CompletableFuture`.
- Replication and storage health monitoring.
- Failover-oriented design for improving storage reliability.

**Engineering concepts**

`Distributed Storage` `Parallel I/O` `Replication` `Fault Tolerance`

### 02. MiniRedis — In-Memory Key-Value Store

<sub>JAVA / SPRING BOOT / CONCURRENCY / DESIGN PATTERNS</sub>

A Redis-inspired backend service designed to explore in-memory data access, key expiration, and eviction strategies.

**What I built and explored**

- Core operations: `SET`, `GET`, `DELETE`, and `EXISTS`.
- TTL-based expiration with lazy expiration and scheduled cleanup.
- LRU, LFU, and FIFO eviction strategies.
- Strategy Pattern for interchangeable eviction policies.
- Thread-safe data access using `ConcurrentHashMap`.

**Engineering concepts**

`Key-Value Storage` `Thread Safety` `TTL` `Cache Eviction`
