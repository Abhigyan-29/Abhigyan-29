### MiniRedis — In-Memory Key-Value Store

`JAVA` `SPRING BOOT` `CONCURRENCY` `DESIGN PATTERNS`

- `SET`, `GET`, `DELETE`, and `EXISTS` operations.
- TTL-based expiration and scheduled cleanup.
